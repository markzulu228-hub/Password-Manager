# Password Manager

An encrypted desktop password manager written in Java (Swing). Your logins live in a
single encrypted file on your own computer. No account, no server.

> **Status:** personal project, not independently audited. See [SECURITY.md](SECURITY.md).

## Features
* **Encrypted vault:** AES-256-GCM, key derived from your master password (PBKDF2, 210,000 iterations)
* **Entries:** site, username, password, website, category, notes, optional 2FA key
* **Password generator** with a live strength meter, and a **security audit** (weak, reused, old)
* **Breach check** via Have I Been Pwned (only a partial hash is sent)
* **2FA codes** (TOTP) with a countdown, like an authenticator app
* **Auto-type** into other apps, **copy with auto-clearing clipboard**, open site in browser
* **Password history**, **undo delete**, search and sort, automatic backup file
* **Import / export CSV** (Chrome, Bitwarden, old `passwords.txt`)
* **Cloud-folder sync:** keep the vault in Dropbox, OneDrive or Google Drive; changes from
  different computers are merged automatically
* Auto-lock when idle, delay after wrong master passwords, change master password
* Shortcuts: `Ctrl+N` add, `Ctrl+F` search, `Ctrl+T` auto-type, `Ctrl+L` lock, `Ctrl+Z` undo delete

## Download
Installers for Windows, macOS and Linux are on the **[Releases](../../releases)** page.
Unsigned builds show an "unknown developer" warning the first time:
* Windows: **More info > Run anyway**
* macOS: right-click the app > **Open**

## Run from source
Needs JDK 17 or newer.

    javac -d out src/PasswordManager.java
    java -cp out PasswordManager

## Where your data lives
* Windows: `%APPDATA%\PasswordManager\vault.dat`
* macOS: `~/Library/Application Support/PasswordManager/vault.dat`
* Linux: `~/.local/share/password-manager/vault.dat`

Uninstalling does not delete the vault. Move it with *Tools > Vault location and sync*.

## Build installers yourself
`jpackage` cannot cross-compile, so build on the system you are targeting. Requires JDK 17+
(Windows also needs the free [WiX Toolset 3.x](https://wixtoolset.org)).

| System  | Command                                   | Output in `build/installer` |
|---------|-------------------------------------------|-----------------------------|
| Windows | `build-windows.bat`                       | `.exe` installer            |
| macOS   | `bash build-mac.sh`                       | `.dmg`                      |
| Linux   | `bash build-linux.sh` (or `rpm`, `app-image`) | `.deb` / `.rpm` / folder |

Set `APP_VERSION=1.2.3` first to change the version number.

## Releasing with GitHub Actions
Pushing a version tag builds all three installers and publishes them as a GitHub Release:

    git tag v1.0.0
    git push origin v1.0.0

You can also run **Actions > Test, build and release > Run workflow** to build installers
without publishing a release. Every push and pull request runs the automated tests.

## Run the tests
    mkdir -p build/test build/run
    javac -d build/test src/PasswordManager.java test/ManagerTests.java
    cd build/run && java -Djava.awt.headless=true -cp ../test ManagerTests

## Project layout
    src/PasswordManager.java       the whole app (single file)
    test/ManagerTests.java         automated tests: crypto, TOTP, CSV, sync/merge, auto-type
    build-*.bat / build-*.sh       installer scripts (jpackage)
    .github/workflows/build.yml    CI: tests, installers, releases
    assets/icon.png                app icon (also generated by the app itself)

## Privacy of this repository
`.gitignore` blocks vault files, backups, CSV exports and conflict copies so you cannot
commit your passwords by accident. Never upload your own `vault.dat`.
